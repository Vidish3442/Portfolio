# Vidish Kumar - Portfolio Website

A modern, responsive, and error-free portfolio website showcasing my journey as a Data Scientist, Machine Learning Engineer, and AI/ML Enthusiast.

## 🚀 Features

### ✨ **Enhanced Design & UX**
- **Modern Design**: Clean, professional layout with smooth animations
- **Dark/Light Mode**: Toggle between themes with smooth transitions and system preference detection
- **Fully Responsive**: Works perfectly on all devices (mobile, tablet, desktop)
- **Interactive Elements**: Engaging hover effects, smooth scrolling, and dynamic content
- **Performance Optimized**: Fast loading with optimized images and lazy loading
- **Accessibility First**: WCAG compliant with proper focus management and screen reader support

### 🌙 **Dark Mode Features**
- **Smart Detection**: Automatically detects and respects system dark mode preference
- **Manual Toggle**: Click the moon/sun icon in navigation or use keyboard shortcut (Ctrl/Cmd + Shift + T)
- **Persistent Storage**: Remembers your theme preference across browser sessions
- **Smooth Transitions**: Seamless animations when switching between light and dark themes
- **Comprehensive Coverage**: All components, forms, and interactive elements adapt to both themes
- **Enhanced Contrast**: Optimized colors for better readability in both modes

### 🎯 **Key Sections**
1. **Hero Section**: Animated introduction with typing effects
2. **About**: Personal background with interactive statistics
3. **Experience**: Professional timeline with hover animations
4. **Skills**: Categorized technical skills with interactive tags
5. **Projects**: Featured projects with live demos and GitHub links
6. **Education**: Academic background timeline
7. **Achievements**: Notable accomplishments and recognitions
8. **Testimonials**: Professional feedback and recommendations
9. **Contact**: Interactive contact form with email integration

### 🛠️ **Technical Excellence**
- **Error-Free Code**: Comprehensive validation and testing
- **Cross-Browser Compatible**: Works on all modern browsers
- **SEO Optimized**: Proper meta tags, structured data, and semantic HTML
- **Progressive Enhancement**: Works without JavaScript, enhanced with it
- **Security Focused**: Secure external links and form validation
